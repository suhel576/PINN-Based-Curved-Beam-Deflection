1
Problem Setup — Governing Equation
▶

A simply supported curved beam under Uniformly Distributed Load (UDL) follows the Euler-Bernoulli beam equation:

EI · d⁴w/dx⁴ = q(x)

Where w(x) = deflection, EI = flexural rigidity, q = load per unit length. For a curved beam with curvature κ, a correction factor is applied:
(1 + 0.15κL) to account for arc geometry effects.

Boundary conditions (simply supported):

w(0) = 0  |  w(L) = 0  |  w''(0) = 0  |  w''(L) = 0

Analytical solution: δ_max = 5qL⁴ / (384·EI) at midspan

2
What is a PINN?
▶

A Physics-Informed Neural Network is a regular neural network that is trained with two types of loss simultaneously:

1. Physics Loss (L_phys): At "collocation points" x₁, x₂, ..., xₙ inside the domain, we enforce that the neural network satisfies the ODE. We compute d⁴w/dx⁴ using automatic differentiation and check if it equals q/EI.

2. Boundary Condition Loss (L_BC): We enforce w(0)=0, w(L)=0, w''(0)=0, w''(L)=0 directly in the loss function.

L_total = L_phys + λ · L_BC

The network learns to satisfy physics without any labeled training data — only the equation and boundary conditions are needed.

3
Neural Network Architecture
▶

Input: position x ∈ [0, L] (normalized to [0,1]). Output: predicted deflection ŵ(x).

# Network: 1 → 20 → 20 → 20 → 1
class PINN(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(1, 20),   # input layer
            nn.Tanh(),
            nn.Linear(20, 20),  # hidden layer 1
            nn.Tanh(),
            nn.Linear(20, 20),  # hidden layer 2
            nn.Tanh(),
            nn.Linear(20, 1)    # output: w(x)
        )
    def forward(self, x):
        return self.net(x)

Why tanh? Because we need to compute 4th-order derivatives (d⁴w/dx⁴) via autograd. tanh is infinitely differentiable — ReLU would give zero higher derivatives.

4
Computing 4th Derivative (Autograd)
▶

The key PINN trick: use automatic differentiation to compute d⁴w/dx⁴ symbolically through the network graph.

def grad(y, x):
    return torch.autograd.grad(
        y, x,
        grad_outputs=torch.ones_like(y),
        create_graph=True,  # keep graph for higher-order
        retain_graph=True
    )[0]

# Compute 4th derivative chain:
w     = model(x_col)
dw    = grad(w, x_col)
d2w   = grad(dw, x_col)
d3w   = grad(d2w, x_col)
d4w   = grad(d3w, x_col)

# Physics residual:
phys_loss = torch.mean((d4w - q/EI) ** 2)

At each training step, the residual (d⁴w/dx⁴ − q/EI) at 200 collocation points is driven to zero by gradient descent.

5
Training Loop & Loss Combination
▶
optimizer = Adam(model.parameters(), lr=1e-3)

for epoch in range(3000):
    optimizer.zero_grad()

    # --- Physics Loss ---
    d4w = fourth_derivative(model, x_colloc)
    L_phys = mse(d4w, q/EI)

    # --- Boundary Condition Loss ---
    w0   = model(x=0)
    wL   = model(x=L)
    d2w0 = second_deriv(model, x=0)
    d2wL = second_deriv(model, x=L)
    L_BC = w0**2 + wL**2 + d2w0**2 + d2wL**2

    # --- Total Loss ---
    loss = L_phys + 10.0 * L_BC

    loss.backward()
    optimizer.step()

λ = 10.0 on BC loss makes sure boundary conditions are enforced strictly. The physics and BC losses compete and converge together.

6
Curvature Correction for Curved Beam
▶

For a straight beam, standard EB theory applies. For a curved beam with curvature κ (= 1/R where R = radius of curvature), the neutral axis shifts and the effective stiffness changes:

w_curved(x) ≈ w_straight(x) × (1 + 0.15 · κ · L)

More rigorously, the Winkler-Bach curved beam theory adds a correction term involving the cross-section geometry and κ. In the PINN, this is incorporated into the physics loss by modifying the effective q/EI ratio:

q_eff / EI = (q / EI) × (1 + β · κ²·R²)

κ = 0 → straight beam (standard EB), κ > 0 → deflection increases due to curvature-induced axial forces.

Complete Python (PyTorch) implementation of the PINN solver. Copy-paste and run directly.

##################################################
#  PINN — Curved Beam Deflection Solver
#  Simply supported + UDL
#  Requires: torch, numpy, matplotlib
##################################################

import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt

# ─────────────────────────────────────────
# 1. Parameters
# ─────────────────────────────────────────
q     = 1000.0    # UDL (N/m)
L     = 4.0       # Beam length (m)
EI    = 50000.0  # Flexural rigidity (N·m²)
kappa = 0.2      # Curvature 1/m (0 = straight beam)

N_col = 200      # collocation points (inside domain)
N_bc  = 10       # points near each boundary
EPOCHS= 3000
lr    = 1e-3
lam   = 10.0     # BC loss weight

# ─────────────────────────────────────────
# 2. Neural Network (PINN model)
# ─────────────────────────────────────────
class BeamPINN(nn.Module):
    """
    Input:  x ∈ [0, L]  (normalized to [0,1] internally)
    Output: predicted deflection w(x)
    Architecture: 1 → 20 → 20 → 20 → 1  with tanh activation
    tanh is chosen because we need 4th-order derivatives.
    """
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(1, 20),
            nn.Tanh(),
            nn.Linear(20, 20),
            nn.Tanh(),
            nn.Linear(20, 20),
            nn.Tanh(),
            nn.Linear(20, 1)
        )
        # Xavier init for smoother training
        for m in self.modules():
            if isinstance(m, nn.Linear):
                nn.init.xavier_normal_(m.weight)
                nn.init.zeros_(m.bias)

    def forward(self, x):
        x_norm = x / L        # normalize to [0,1]
        return self.net(x_norm)

# ─────────────────────────────────────────
# 3. Automatic Differentiation helpers
# ─────────────────────────────────────────
def grad(y, x):
    """Compute dy/dx using autograd (keeps graph for higher-order)."""
    return torch.autograd.grad(
        y, x,
        grad_outputs=torch.ones_like(y),
        create_graph=True,
        retain_graph=True
    )[0]

def deriv4(model, x):
    """Compute d⁴w/dx⁴ at points x."""
    w   = model(x)
    dw  = grad(w,  x)
    d2w = grad(dw, x)
    d3w = grad(d2w, x)
    d4w = grad(d3w, x)
    return w, d2w, d4w

# ─────────────────────────────────────────
# 4. Collocation & boundary points
# ─────────────────────────────────────────
# Interior collocation points (requires_grad for autograd)
x_col = torch.linspace(0, L, N_col).view(-1, 1).requires_grad_(True)

# Boundary points
x0    = torch.tensor([[0.0]]).requires_grad_(True)
xL    = torch.tensor([[L]]).requires_grad_(True)

# Curvature correction factor
curve_factor = 1.0 + 0.15 * kappa * L
q_eff = q * curve_factor   # effective load for curved beam

# ─────────────────────────────────────────
# 5. Training
# ─────────────────────────────────────────
model     = BeamPINN()
optimizer = torch.optim.Adam(model.parameters(), lr=lr)
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=500, gamma=0.8)
losses    = []

for ep in range(EPOCHS):
    optimizer.zero_grad()

    # ── Physics Loss ──
    w_col, d2w_col, d4w_col = deriv4(model, x_col)
    L_phys = torch.mean((d4w_col - q_eff / EI) ** 2)

    # ── Boundary Condition Loss ──
    w0,  d2w0,  _ = deriv4(model, x0)
    wL_, d2wL_, _ = deriv4(model, xL)
    L_BC = (w0**2 + wL_**2           # w(0)=0, w(L)=0
           + d2w0**2 + d2wL_**2).mean()  # w''(0)=0, w''(L)=0

    # ── Total Loss ──
    loss = L_phys + lam * L_BC
    loss.backward()
    optimizer.step()
    scheduler.step()
    losses.append(loss.item())

    if ep % 500 == 0:
        print(f"Epoch {ep:4d} | loss={loss.item():.6f} | L_phys={L_phys.item():.6f} | L_BC={L_BC.item():.6f}")

# ─────────────────────────────────────────
# 6. Evaluate & Plot
# ─────────────────────────────────────────
x_test = torch.linspace(0, L, 200).view(-1, 1)
with torch.no_grad():
    w_pred = model(x_test).numpy().flatten()

x_np   = x_test.numpy().flatten()

# Analytical solution
w_anal = (q / (24 * EI)) * x_np * (L**3 - 2*L*x_np**2 + x_np**3)
w_curv = w_anal * curve_factor

print(f"\nMax PINN deflection    : {w_pred.max()*1000:.4f} mm")
print(f"Max Analytical (curved): {w_curv.max()*1000:.4f} mm")
print(f"5qL4/384EI (straight)  : {5*q*L**4/(384*EI)*1000:.4f} mm")

fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].plot(x_np, w_pred*1000, label='PINN', color='#4f9cf9', lw=2)
axes[0].plot(x_np, w_anal*1000, label='Analytical (straight)', color='#29d9a3', lw=1.5)
axes[0].plot(x_np, w_curv*1000, label='Curved correction', color='#f97b4f', lw=1.5, ls='--')
axes[0].set_xlabel('x (m)'); axes[0].set_ylabel('w (mm)')
axes[0].set_title('Deflection Profile'); axes[0].legend(); axes[0].grid(alpha=0.3)

axes[1].semilogy(losses, color='#4f9cf9', lw=1.5)
axes[1].set_xlabel('Epoch'); axes[1].set_ylabel('Loss (log)')
axes[1].set_title('Training Loss Convergence'); axes[1].grid(alpha=0.3)

plt.tight_layout()
plt.savefig('pinn_curved_beam.png', dpi=150)
plt.show()
